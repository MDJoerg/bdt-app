# Quickstart-Tutorials

Kurze, durchgespielte Anleitungen zum Ausprobieren. Die meisten Tutorials nutzen dasselbe
Beispiel: das **Musterprojekt „Sascha, der Servicetechniker"**. Sascha wartet Klimaanlagen im
Außendienst. Unterwegs hat er die Hände voll und nutzt einen KI-Assistenten per Sprache, in der
Pause das Smartphone, und im Büro auch einen Laptop.

| Tutorial | Worum es geht | Dauer |
|---|---|---|
| [Musterprojekt „BDT Schnelleinstieg“](musterprojekt-schnelleinstieg.md) | Was BDT kann: Steckbrief je Kachel, Konzepte, Personas mit Lernpfad, Neues in der Preview | 15 Min. |
| [Preview: Rundgang „Von der Anforderung zur Lösung“](preview-sascha-rundgang.md) | Tester-Blatt: Szenario Sascha im Architektur-Studio, vom Workshop bis zur Übergabe | 45 Min. |
| [Musterprojekt einrichten](musterprojekt-sascha.md) | Musterprojekt importieren, bei Bedarf als Kopie unter neuem Namen | 5 Min. |
| [BDT mit Claude fernsteuern (MCP)](mcp-claude-code.md) | Claude Code an das BDT-MCP-Gateway anbinden und fünf Kacheln per Chat bedienen | 20 Min. |
| [CDS-Modell und Hierarchie erzeugen](cds-generierung.md) | Selbstlernkurs mit eigenem Musterprojekt: Datenkatalog, CDS-View, Hierarchie, OData, ABAP Generator | 90 Min. |
