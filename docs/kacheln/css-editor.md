# CSS-Editor

Schreibt eigenes CSS und testet es direkt gegen Beispiel-Markup – z. B. um ein eigenes Theme für
den [Marp-Editor](marp-editor.md) zu gestalten.

## Voraussetzungen

- Ein Projekt.
- Kein SAP-Endpunkt nötig.

## Typischer Ablauf

1. „Neues Objekt" öffnet einen leeren Stylesheet-Text.
2. CSS schreiben, Wirkung direkt an einem Beispiel-Markup sehen.
3. Speichern.

## Funktionen im Detail

- Gespeicherte Stylesheets stehen als eigener Infotyp zur Verfügung, z. B. für den
  [Marp-Editor](marp-editor.md).

## Tipps & Grenzen

- Die Vorschau nutzt ein festes Beispiel-Markup – prüfe das Ergebnis zusätzlich an der
  tatsächlichen Zielumgebung (z. B. den echten Marp-Folien).
