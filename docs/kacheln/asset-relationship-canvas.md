# Beziehungs-Canvas

Modelliert Asset-Beziehungen visuell per Drag & Drop auf einer Zeichenfläche – die grafische
Alternative zur listenbasierten Pflege in [Beziehungen](asset-relationship-manager.md).

## Voraussetzungen

- Ein Projekt mit mindestens einem Asset-Universum.
- Kein SAP-Endpunkt nötig.

## Typischer Ablauf

1. Universum wählen.
2. Assets auf die Fläche ziehen.
3. Zwei Assets durch eine Kante verbinden – legt die eigentliche Beziehung an.
4. Layout nach Bedarf per Autofit anordnen.

## Funktionen im Detail

- Änderungen auf der Canvas wirken direkt auf die zugrunde liegenden Beziehungsdaten – keine
  reine Zeichnung ohne Datenbezug.

## Tipps & Grenzen

- Bei sehr vielen Assets/Beziehungen ist die listenbasierte Pflege unter
  [Beziehungen](asset-relationship-manager.md) oft übersichtlicher.
