# JSON-Editor

Prüft, formatiert und modelliert JSON – mit Syntax-Hervorhebung und Fehleranzeige, auch für ein
zugehöriges JSON-Schema.

## Voraussetzungen

- Ein Projekt.
- Kein SAP-Endpunkt nötig.

## Typischer Ablauf

1. „Neues Objekt" öffnet ein leeres JSON-Dokument.
2. JSON eintippen oder einfügen – Syntaxfehler werden direkt markiert.
3. Optional gegen ein Schema validieren.
4. Speichern.

## Funktionen im Detail

- Formatiert (Pretty-Print) auf Knopfdruck.

## Tipps & Grenzen

- Für sehr große JSON-Dateien kann das Formatieren spürbar dauern.
