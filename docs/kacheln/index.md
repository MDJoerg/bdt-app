# Kachel-Dokumentation

Jede Kachel im Detail – gruppiert wie im Launchpad. Die Gruppen „Favoriten" und „Neuigkeiten"
haben keine eigenen Seiten hier: Favoriten sind eine reine Merkliste, Neuigkeiten-Kacheln
entstehen dynamisch aus den [News-Quellen](news-sources.md), die du selbst einrichtest.
