# Seiten-Baukasten

Baut Web-Seiten und Wireframes per Drag & Drop – vorgefertigte Blöcke (Text, Bilder, Buttons,
Layout-Raster) auf eine Fläche ziehen, statt HTML von Hand zu schreiben.

## Voraussetzungen

- Ein Projekt.
- Kein SAP-Endpunkt nötig.

## Typischer Ablauf

1. „Neues Objekt" – dabei die Variante wählen: **Webseite** (ausformuliertes Design) oder
   **Wireframe** (grobe Skizze/Platzhalter).
2. Blöcke aus der Palette auf die Fläche ziehen und anordnen.
3. Eigenschaften/Styling der Blöcke im Seitenpanel anpassen.
4. Speichern.

## Funktionen im Detail

- Zwei Varianten für unterschiedliche Zwecke: **webpage** für ein tatsächliches Design,
  **wireframe** für eine schnelle, bewusst grobe Skizze.
- Direkte Vorschau der zusammengesetzten Seite ohne Zwischenschritt.

## Tipps & Grenzen

- Der Baukasten eignet sich für Skizzen/Prototypen – für produktiven Code-Export prüfe das
  Ergebnis vor der Weiterverwendung.
